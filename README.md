# 🦑 Axolotl Tracker - Demo App

A simple, mobile-friendly web app to track your axolotl's feedings and tank health.

**⚠️ DEMO APPLICATION ONLY** - Not for production use. Data stored locally on your device.

## Features

- 📅 **Calendar Dashboard** - Visual calendar of feeding dates
- 🍽️ **Feeding Logger** - Log date, food type, and amount
- 🏠 **Tank Status Tracker** - Track looks, happiness, activity level, notes
- 📊 **Analytics** - View feeding frequency and trends
- ✏️ **Edit & Delete** - Modify or remove any log entries
- 🦑 **Pet Name** - Name and manage your axolotl

## Usage

1. Open `index.html` in your browser
2. Login with the demo credentials provided in the app
3. Start logging feedings and tank observations
4. All data is stored locally on your device

## Technical Details

- **Storage**: Browser localStorage (no server, no cloud sync)
- **Framework**: Vanilla HTML/CSS/JavaScript (no dependencies)
- **Hosting**: Works anywhere - GitHub Pages, local file, any web server
- **Mobile**: Fully responsive for phone and tablet

## Data Privacy

✅ **All data stays on your device**  
✅ **No internet sync**  
✅ **No tracking**  
✅ **No accounts**  

Data persists in your browser until you clear localStorage.
